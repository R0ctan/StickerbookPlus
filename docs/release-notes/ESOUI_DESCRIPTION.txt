[CENTER][SIZE="6"][b]Stickerbook+[/b][/SIZE][/CENTER]
[CENTER][SIZE="3"]Stop scrolling past hundreds of things you already own to find the one you don't.[/SIZE][/CENTER]

[SIZE="3"][b]Your Stickerbook knows everything about your collection. It's just really bad at telling you.[/b] Finished a Cyrodiil run and got a new item? Good luck finding that one tiny "new" icon among hundreds you already own. Stickerbook+ ends the scavenger hunt: new and missing entries marked right on the tiles, category trees colored by completion, incomplete entries sorted to the top.[/SIZE]

[SIZE="2"]Six areas, one fix: Item Sets Book, Outfit Styles, Antiquities Codex, Achievements, Lore Library, and Collections. Every marker, color, and sorting option below is fully configurable and can be toggled per area — see the [b]Settings[/b] section near the bottom. Screenshots and details for each area follow below.[/SIZE]

[SIZE="5"][b][color=#DAA520]Settings[/color][/b][/SIZE]
[IMG]https://raw.githubusercontent.com/R0ctan/StickerbookPlus/main/docs/assets/sbp_settings.jpg[/IMG]
[SIZE="2"][b][color=#DAA520][1][/color][/b] Active Areas — turn Stickerbook+ on or off per area (Item Sets, Outfit Styles, Collections, Lore Library, Achievements, Antiquities), independent of each other.[/SIZE]
[SIZE="2"][b][color=#DAA520][2][/color][/b] New Marker — customize the border and background color, thickness, and whether ESO's native "new" icon is hidden.[/SIZE]
[SIZE="2"][b][color=#DAA520][3][/color][/b] Missing Marker — customize the background color for missing items, and choose per area whether it's shown at all.[/SIZE]
[SIZE="2"][b][color=#DAA520][4][/color][/b] Tree: Coloring & Counting per Area — per-area switches for tree coloring and missing-count suffixes (categories, subcategories, chain stages, and more).[/SIZE]
[SIZE="2"][b][color=#DAA520][5][/color][/b] Tree: Color Levels — set the four shared colors used everywhere: complete, partial, missing, and selected.[/SIZE]
[SIZE="2"][b][color=#DAA520][6][/color][/b] Sorting — toggle "missing first" sorting independently for each of the five supported areas.[/SIZE]
[SIZE="2"][b][color=#DAA520][7][/color][/b] Dismiss Markers — show or hide the "Clear New Status" button, and pick its label text.[/SIZE]
[SIZE="2"][b][color=#DAA520][8][/color][/b] Advanced — chat messages, internal ID display in tooltips, and Crown Store tag settings.[/SIZE]
[SIZE="2"][b][color=#DAA520][9][/color][/b] Long entry names — tree entries that don't fit are truncated with a tooltip instead of wrapping or overflowing.[/SIZE]

[b]Slash command[/b]
[SIZE="2"]/sbp
- /sbp on — enable the addon
- /sbp off — disable the addon
- /sbp test item [itemId] — mark a specific Item Sets piece as new for testing
- /sbp test style [collectibleId] — mark a specific Outfit Style as new for testing
- /sbp test collection [collectibleId] — mark a specific Collections item as new for testing[/SIZE]
