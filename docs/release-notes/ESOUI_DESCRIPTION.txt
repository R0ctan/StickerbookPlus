[CENTER][SIZE="6"][b]Stickerbook+[/b][/SIZE][/CENTER]
[CENTER][SIZE="3"]Stop scrolling past hundreds of things you already own to find the one you don't.[/SIZE][/CENTER]

[SIZE="4"][b]Your Stickerbook knows everything about your collection. It's just really bad at telling you.[/b][/SIZE] [SIZE="3"]Finished a Cyrodiil run and got a new item? Good luck finding that one tiny "new" icon among hundreds you already own. Stickerbook+ ends the scavenger hunt: new and missing entries marked right on the tiles, category trees colored by completion, incomplete entries sorted to the top.[/SIZE]

Six areas, one fix: Item Sets Book, Outfit Styles, Antiquities Codex, Achievements, Lore Library, and Collections. Every marker, color, and sorting option below is fully configurable and can be toggled per area — see the [b]Settings[/b] section near the bottom. Screenshots and details for each area follow below.

[b]Slash command[/b]
/sbp
- /sbp on — enable the addon
- /sbp off — disable the addon
- /sbp test item [itemId] — mark a specific Item Sets piece as new for testing
- /sbp test style [collectibleId] — mark a specific Outfit Style as new for testing
- /sbp test collection [collectibleId] — mark a specific Collections item as new for testing
