[size=4][b]Version 1.0.1[/b][/size]

Bugfix release — recommended for everyone. Fixes several cases where "new" items were not highlighted.

[size=3][b]Fixed:[/b][/size]
- Clicking an achievement link in chat no longer shows Stickerbook+ coloring on the achievement popup.
- Item Sets Book: set pieces you have just unlocked are now correctly highlighted as new.
- Antiquities Codex: newly discovered leads are now correctly highlighted as new — both on the tile and on the individual fragment icons.
- The "Hide ESO's new icon" option now also works in the Antiquities Codex (previously it only worked for Item Sets, Outfit Styles, and Collections).
